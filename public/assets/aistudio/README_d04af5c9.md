# Arafat Portfolio Website

A responsive portfolio made with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `arafat-portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Personalize it before publishing
- In `index.html`, change the name, bio, education details and project descriptions.
- Replace `your.email@example.com` with your real email address.
- Replace the GitHub, LinkedIn and Facebook profile links with your own URLs.
- Update the skill names and the illustrative progress bars in `index.html`.
- Add real project/demo links if you have them.

The contact button uses `mailto:`. It opens the visitor's email app; it does not submit to a server.
